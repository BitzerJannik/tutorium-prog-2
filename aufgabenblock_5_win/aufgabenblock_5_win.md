### 1.1 Box

Wir wollen eine Schachtel (Box) definieren, welche einen bestimmten Datentyp speichert. 
Bisher muessten wir fuer jeden Typ eine separate Box definieren..
Mit Generischen Klassen definieren wir eine universelle Box und 
koennen damit fuer alle die gleiche, generische Klasse verwenden.

**Aufgaben:**
- schreibe eine generische Klasse Box
- jede Box soll eine Set und eine Get-Methode haben
- teste den Code in einer Datei mit verschiedenen Typen, zum
  Beispiel int, String, double, ect.

# Aufgaben Tutorium Programmierung 2 Wintersemester 2025/2026

## Download Repo via git
Um den Ordner lokal auf euren Rechner zu kopieren, oeffent ein Terminal in eurem gewuenschten Zielordner und
gebt folgendes Kommando im Terminal ein:

`git clone https://github.com/BitzerJannik/tutorium-prog-2.git`

Das erstellt einen Ordner mit dem Namen tutorium-prog-2.

Alternativ konennt ihr auch ueber den gruenen Button namens `Code` die Dateien als ZIP-Ordner herunterladen.
